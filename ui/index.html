ขั้นตอนการเปิด USB Debugging (ทั่วไป)

  1. ไปที่ การตั้งค่า (Settings) > เกี่ยวกับโทรศัพท์ (About Phone)
  2. แตะที่ หมายเลขบิลด์ (Build Number) รัวๆ 7 ครั้ง จนขึ้นว่า "คุณเป็นนักพัฒนาแล้ว"
  3. ย้อนกลับมาที่ การตั้งค่าเพิ่มเติม (System / Additional Settings) > ตัวเลือกสำหรับนักพัฒนา (Developer Options)
  4. เปิดสวิตช์ การแก้จุดบกพร่อง USB (USB Debugging)
  5. เสียบสายต่อเข้าคอมพิวเตอร์ และดูที่หน้าจอมือถือ กดยอมรับ "อนุญาตเสมอ (Always Allow)"
